# Project Instructions

## Overview

A great little tool that prints Hello World. 

For all those times when you need someone to say "Hello World".

## This file

This file gives information to Claude about the project. 

You can also have one one of these in your home directory.

Think of this file as informational only. It's more of a set of guidelines to Claude and not a set of rules that Claude must follow. Claude will ignore things in this file, especially as it runs out of context.

Keep this file small. Unecessary information here pollutes Claude's context for no good reason.

## Rules

- Do not use em dashes.

## Development

- Entry point: `src/index.js`
- Run with: `npm start`
- Test with: `npm test`

## Testing

Tests use [Jest](https://jestjs.io/). Test files live alongside source files with `.test.js` suffix.
